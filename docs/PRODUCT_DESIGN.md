# 轻办公工具箱：产品设计文档

## 1. 产品概述

轻办公工具箱是一个免登录的在线办公工具网站，首期解决两类高频问题：

1. Excel、XLS、CSV 表格的拆分与合并。
2. 二维码生成、二维码图片解析及 MAC 地址二维码制作。

项目当前以个人学习、作品展示和公网演示为主要目标，同时保证普通办公用户可以完成真实操作。

## 2. 目标用户

- 主要读者：作品评审者、面试官和项目开发者。
- 实际使用者：需要快速拆分或合并表格、生成二维码、解析二维码及转换 MAC 地址的普通办公用户。
- 使用特点：核心工具免登录即可使用；需要历史记录的用户可以注册数字账号，文件不会长期保存。

## 3. 产品目标与成功标准

### 目标

- 用户可以在首页第一眼看到所有可执行功能。
- 用户选择功能后直接进入对应工作台，无需理解技术分类。
- 匿名工具流程不依赖账号；个人历史和权限功能使用账号和数据库。
- 通过完整前端、后端分层、自动化测试和部署能力展示全栈工程水平。

### 成功标准

- 新用户可以独立完成一次表格拆分或二维码生成。
- Excel/CSV 拆分和合并结果正确，输出文件可以正常打开。
- 二维码生成尺寸正确，图片解析能返回全部识别内容。
- 桌面和移动端均可完成主要流程。
- 后端测试、前端构建和 Playwright 主流程测试全部通过。

## 4. 信息架构

### 首页：功能选择

首页是欢迎与功能选择页，不承担复杂业务操作。首屏展示五个入口：

- 拆分 Excel / CSV
- 合并多个表格
- 生成二维码
- 解析二维码图片
- 制作 MAC 地址二维码

点击入口后进入相应工作台，并通过 URL 参数预选处理模式或页签。

### Excel / CSV 工作台

操作流程：

1. 上传一个或多个表格文件。
2. 读取并展示文件、工作表、行数、列数和表头。
3. 选择一个或多个工作表。
4. 选择工作表拆分、按行数拆分、按列值拆分或数据合并。
5. 设置表头、空行、重复行及合并策略。
6. 查看处理进度和结果摘要。
7. 下载结果。

### 二维码 / MAC 工具

包含三个独立页签：

- 生成二维码：普通文本或 URL 转 PNG。
- 图片解析：上传 PNG、JPEG 或 WebP，展示全部去重后的二维码内容。
- MAC 地址：校验已有 MAC 地址、展示常见格式并生成二维码。

## 5. 功能规则

### Excel / CSV

- 支持 `.xlsx`、`.xls`、`.csv`。
- 单文件最大 50MB，单任务最多 20 个文件，总计不超过 100MB。
- 按工作表拆分时，每个被选中的工作表生成一个独立单表文件。
- 按行数拆分时，每份 1 至 50000 条数据行，表头不计入行数。
- 按列值拆分时，同一列值的数据进入同一个文件。
- 合并时支持严格表头及按列名对齐两种策略。
- 首行表头默认开启；关闭后使用“列1、列2……”作为内部列标识。
- 去除空行和重复行默认关闭。
- Excel 输出以值数据为主，不保留公式、样式、图片、批注和宏。
- CSV 拆分结果保持 CSV 格式，并使用 UTF-8 BOM 提升中文兼容性。
- 混合格式合并统一输出 `.xlsx`。
- 拆分结果统一打包为 ZIP，合并结果为单个 `.xlsx`。

### 二维码 / MAC

- 二维码尺寸范围 128 至 2048 像素，默认 512 像素。
- 二维码输出为黑白 PNG。
- 图片解析最多 10MB、4000 万像素。
- MAC 地址必须为 12 位十六进制字符。
- 支持冒号、连字符、Cisco 点分和纯十六进制格式。
- MAC 地址统一规范化为 `AA:BB:CC:DD:EE:FF` 后生成二维码。
- 不随机生成 MAC 地址。

## 6. 体验与隐私

- 当前前端默认开启演示模式，页面明确显示“演示模式 · 数据为模拟”。
- 演示模式下 Excel 处理和二维码解析使用模拟数据，二维码生成在浏览器中真实完成。
- 正式后端模式下，上传文件和结果默认保留 30 分钟，随后自动清理。
- 匿名用户不建立处理历史。
- 登录用户可保存处理结果到个人历史；每用户最多 10 个活跃结果或 200MB。
- 历史文件完成后保留 30 分钟，过期占位记录保留 3 小时，不长期保存文件。
- 错误信息使用可理解的中文说明，不只暴露技术错误码。

## 7. 版本路线

### 一期：完整 MVP

- 完成首页功能选择、Excel/CSV 工作台和二维码/MAC 工具。
- 完成基础后端接口、文件校验、临时文件清理、自动化测试和部署配置。

### 二期：运维加固

- 文件日志与轮转、请求追踪、接口限流、错误告警。
- 同源部署优先；只有使用独立前端域名时才配置受限 CORS。

### 三期：账号与数据

- 用户注册、登录、JWT Bearer 鉴权、MySQL 和 SQLAlchemy。
- 数字用户名 8–18 位，密码 8–18 位，支持自定义找回问题和答案。
- 保存限时处理历史，管理员可管理账号并查询审计日志。
- 历史记录必须按用户隔离，数据库变更使用迁移工具管理。
- 此阶段已完成；常用配置不在本期范围。

### 四期 A：轻量异步任务

- 返回 `task_id`，提供排队、运行、成功、失败和过期状态。
- 限制并发和排队数量，前端轮询展示处理进度。
- 接受单进程任务状态在服务重启后丢失的限制。

### 四期 B：正式任务队列

- 当任务耗时、排队或可靠性达到明确瓶颈后，升级为 Redis 与独立 Worker。
- 替换任务执行器，保持任务状态和下载接口兼容，避免前端重写。

## 8. 非目标

- 首期不提供会员、支付、复杂角色权限或多租户。
- 不承诺 Excel 公式、样式、图表和图片完整保真。
- 不在 MVP 中实现跨实例任务队列或百万行级表格处理。
- 不通过让用户手工裁切文件来掩盖系统容量限制。

## 9. 验收标准

- 首页五个入口清晰可见，点击后进入正确模式或页签。
- Excel/CSV 的三种拆分与一种合并流程可完整操作。
- xlsx、xls 和中文 CSV 均可读取，结果文件可被 Excel 正常打开。
- 二维码生成可下载 PNG，图片解析可展示多个二维码内容。
- MAC 地址可实时校验并生成二维码。
- 错误场景有明确提示，不出现无反馈的卡死状态。
- ESLint、TypeScript、Next.js 构建和 Playwright 主流程测试通过。
- 匿名工具流程保持可用；无 Token 时登录专属接口返回 401。
- 登录用户历史配额、30 分钟有效期和 3 小时占位符合规则。
- 普通用户无法访问管理员功能，管理员不能查看密码或用户文件。
- 管理员可按日期筛选和下载审计日志、运行错误日志。
