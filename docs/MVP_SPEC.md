# 轻办公工具箱 MVP 规格

## 目标

提供免登录的 Excel/CSV 拆分合并与二维码/MAC 地址生成解析工具。首版不包含账号、数据库、历史记录、广告或付费能力。

## Excel / CSV

- 支持 `.xlsx`、`.xls`、`.csv`；单文件不超过 50MB，单任务不超过 20 个文件且总上传不超过 100MB。
- 上传后展示文件、工作表、行数、列数和表头，并允许选择需要处理的工作表。
- 按工作表拆分时，每个选中工作表输出为独立单表文件。
- 按行数拆分时，单份数据行数为 1 到 50000，表头不计数；每个输出文件重复表头，结果打包为 ZIP。
- 按列值拆分时，按指定列位置分组，每个输出文件重复表头；最多产生 1000 个结果文件。
- 合并时按所选工作表顺序追加到一个工作表。表头支持严格一致和按列名对齐两种策略。
- 首行表头默认开启；关闭后使用“列1、列2……”作为表头。
- 去空行、去重复行默认关闭。空行指所有单元格为空或仅含空白；重复行按全部输出列的实际值比较，文本去除首尾空白。
- Excel 输出只保留值、日期和数字类型，不保留公式、样式、图片、图表、批注或宏。CSV 拆分保持 CSV 格式并使用 UTF-8 BOM 输出。
- 混合格式合并统一输出 `.xlsx`。拆分结果统一打包为 ZIP。

## 二维码 / MAC

- 文本或 URL 生成黑白 PNG，尺寸 128 到 2048 像素，默认 512 像素，中等容错。
- 支持 PNG、JPEG、WebP 上传解析，最大 10MB、4000 万像素；返回图片内全部去重后的二维码内容。
- MAC 模式接受冒号、连字符、点分和纯十六进制格式，规范化为 `AA:BB:CC:DD:EE:FF` 后生成二维码。
- 解析到合法 MAC 地址时返回规范化结果及其无分隔、连字符、Cisco 点分格式。

## 临时文件与安全

- 上传和结果保留 30 分钟，服务每 60 秒清理过期任务。
- 文件磁盘路径使用服务端 UUID，原始文件名仅用于展示和下载文件名。
- xlsx 解压后不超过 250MB、不超过 10000 个条目；单工作表不超过 200000 行和 1000 列。
- Excel 处理最多并发 2 个，单任务超时 120 秒。
- 服务重启后临时上传和下载令牌失效。

## API

- `POST /api/v1/excel/inspect`
- `POST /api/v1/excel/split`
- `POST /api/v1/excel/merge`
- `GET /api/v1/results/{result_id}`
- `POST /api/v1/qrcode/generate`
- `POST /api/v1/qrcode/decode`
- `GET /api/v1/health`

JSON 响应格式为 `{ success, data, error, request_id }`。文件下载成功时直接返回二进制内容。

## 验收

- pytest 覆盖正常流程、参数错误、损坏文件、超限、过期、空行、重复行、表头策略、CSV 编码和并发限制。
- Playwright 覆盖 Excel 拆分为 ZIP、二维码生成、图片解析三条主流程。
- `ruff check`、`pytest`、`pnpm lint`、`pnpm typecheck`、`pnpm build` 和 Playwright 全部通过。
- 生成文件可由 Excel 正常打开，数据、表头、行数、文件名正确；移动端可完成主流程。
